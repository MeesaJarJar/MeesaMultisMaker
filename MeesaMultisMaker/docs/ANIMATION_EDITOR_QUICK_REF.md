## Workflow Shortcuts

### View Animation
1. Select type ? Body ? Action ? Direction
2. Click **? Play**

### Export Frames
1. Load animation
2. Click **Export Frames**
3. Select folder

### Export Sprite Sheet
1. Load animation  
2. Click **Export Sheet**
3. Choose filename

### Replace Frame
1. Load animation
2. Select frame from list
3. Click **Replace Frame**
4. Choose image file

### Save Changes
1. Make edits
2. Click **Save to MUL**
3. Confirm save (creates backup)

## Tips

?? **Search by ID**: Use Body ID box to jump directly  
?? **Loop Mode**: Enable for continuous playback  
?? **Adjust FPS**: Use slider for playback speed (1-60)  
?? **Auto Backup**: Save creates timestamped backups  
?? **Center Point**: Shows visual anchor for each frame  

## File Locations

**Backups**: `{MulFolder}/anim.mul.backup_YYYYMMDDHHMMSS`  
**Exports**: Selected folder / body{X}_action{Y}_dir{Z}/  
**Sprite Sheets**: Selected location with grid layout  

## Troubleshooting

| Issue | Solution |
|-------|----------|
| No animations | Check MUL folder in Settings |
| Can't save | Check write permissions |
| Stuttering | Lower FPS slider |
| Missing frames | Not all actions exist for all bodies |
